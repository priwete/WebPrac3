# Neal Wear — лендинг иллюстратора

Учебный проект по вёрстке (2026–2027, 1 семестр). Тема: услуги веб-дизайнера / иллюстратора.

## Концепция

Выбрано редакционное направление: крупная типографика с левым краем, асимметричная сетка, бумажный фон, кобальтовый и оранжевый акценты. Вместо универсального hero-градиента используется авторская вертикальная иллюстрация — она сразу объясняет характер проекта и остаётся локальным лёгким ассетом.

## Референсы

- [AI Campus / Citadel](https://citadel.study/ai-campus?ref=https://tilda.cc/ru/madeontilda/) — взята идея короткого пути к действию и ясной структуры блоков. Не переносились карточки, тексты и визуальный стиль.
- [A+ Help](https://a-plus.help/?ref=https://tilda.cc/ru/madeontilda/) — понравилась энергичная типографика и чередование плотных/воздушных секций. Не копировалась композиция первого экрана.
- [Made on Tilda](https://tilda.cc/ru/madeontilda/) — источник общей насмотренности по нестандартной сетке и работе с крупными изображениями.

## Реализовано

- семантические HTML5-секции и навигация с якорями;
- CSS Grid/Flexbox, адаптивные брейкпоинты для мобильного и десктопа;
- плавная прокрутка с уважением к `prefers-reduced-motion`;
- мобильное меню;
- модальное окно брифа с закрытием по Escape, клику по фону и ловушкой фокуса;
- клиентская валидация формы с понятными сообщениями и демо-статусом отправки;
- локальные PNG-скриншоты работ с альтернативным текстом и обработкой ошибки изображения;
- повтор основных контактов в футере.

## Запуск

Откройте `index.html` напрямую или запустите любой статический сервер из этой папки. Отправка формы в этом учебном макете не подключена к серверу: после успешной проверки показывается демо-сообщение.
